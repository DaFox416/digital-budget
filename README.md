# Digital Budget

Administrador de gastos e ingresos pensado para México: tarjetas de débito y crédito, fechas de corte y pago, meses sin intereses y un modo ahorro que distingue tu saldo real de lo que de verdad puedes gastar.

> En desarrollo. Demo: 13 de noviembre de 2026 · v1: 4 de diciembre de 2026.

## Stack

FastAPI · PostgreSQL · React + TypeScript · Docker
